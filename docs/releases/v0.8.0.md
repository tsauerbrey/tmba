# TMBA v0.8.0 – First Bootable TMBA-OS

## Ziel

v0.8.0 ist das erste Image, das den aktuellen TMBA-Backend-Stand vollständig in Raspberry Pi OS Lite installiert und nach dem Boot automatisch startet.

## Enthalten

- Installation nach `/opt/tmba`
- Python-Virtualenv unter `/opt/tmba/backend/.venv`
- Runtime-Konfiguration unter `/opt/tmba/config`
- Backend als `tmba-backend.service`
- Bootdiagnose als `tmba-boot-diagnostics.service`
- API-Startprüfung als `tmba-healthcheck.service`
- HiFiBerry-Amp4-Pro-Overlay
- ALSA, AirPlay/`shairport-sync`, Avahi, Bluetooth-Grundpakete und SSH
- Diagnoseprotokolle unter `/var/log/tmba`
- Image-Kennung in `/etc/tmba-image-release`

## Erster Hardwaretest

Nach dem Flashen und Booten:

```bash
ssh tmba@tmba.local
systemctl status tmba-backend --no-pager
systemctl status tmba-healthcheck --no-pager
curl http://127.0.0.1:8000/system/health
cat /etc/tmba-image-release
cat /var/log/tmba/boot.log
aplay -l
```

Das Developer-Passwort lautet für diesen Meilenstein weiterhin `tmba` und muss vor produktiver Nutzung geändert werden.
