# TMBA v0.9.0 – First Hardware Audio

TMBA v0.9.0 connects the backend audio pipeline to the real HiFiBerry Amp4 Pro.

## Included

- correct `dtoverlay=hifiberry-amp4pro`
- ALSA output instead of the simulation driver
- stable named device `hw:CARD=sndrpihifiberry,DEV=0`
- dynamic discovery of the current ALSA card index
- `POST /audio/testtone` for a safe, short hardware test
- regression tests for the Amp4 Pro overlay and named ALSA device

## Hardware validation

The Amp4 Pro was detected as `HiFiBerry AMP4 Pro HiFi pcm512x-hifi-0` and produced a successful stereo test tone on real hardware.
