# TMBA v0.7.3-A

## Developer Image Builder

Dieser Meilenstein führt die reproduzierbare Image-Builder-Struktur ein.

### Enthalten

- festgelegtes Ziel Raspberry Pi 4 / ARM64
- Raspberry Pi OS Lite / Bookworm als Basisdefinition
- deklarative Paket- und Dienstlisten
- geordnete Buildstufen
- Root-Filesystem-Overlay mit Backend-systemd-Unit
- Validator und Dry-Run-Buildplan
- pytest-basierte Builder-Tests
- eigener GitHub-Actions-Workflow

### Noch nicht enthalten

- Download eines Basisimages
- Loop-Mount, chroot oder QEMU
- Erzeugung einer bootfähigen `.img`-Datei
- WLAN-Zugangsdaten oder andere Geheimnisse
