# TMBA-OS v0.6.2-A

## ALSAOutputDriver-Grundgerüst

Dieser Meilenstein schafft die Hardware-Ausgabeabstraktion für Linux und
Raspberry Pi.

## Neu

- `AlsaOutputDriver`
- parserbasierte Auswertung von `aplay -l`
- strukturierte `AlsaDevice`-Einträge
- Linux- und Werkzeugprüfung
- Validierung von `hw:<Karte>,<Gerät>`
- OutputDriver-Factory
- automatische Treiberauswahl durch `AudioPipeline`
- vollständig gemockte Tests für macOS und CI

## Sicheres Verhalten

Die Standardkonfiguration bleibt:

```text
driver = null
device = simulation
```

Der ALSA-Treiber startet in v0.6.2-A noch keinen dauerhaften Audioprozess. Er
prüft ausschließlich Umgebung, Werkzeug und Geräteauswahl. Nach erfolgreicher
Vorbereitung steht sein Zustand auf `ready` und `streaming` bleibt `false`.

## Noch nicht enthalten

- keine PCM-Datenübergabe
- kein dauerhaft laufender `aplay`-Prozess
- keine Auswahl über REST
- keine Raspberry-Pi-Konfigurationsdatei
- kein CamillaDSP
