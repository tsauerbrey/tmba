# TMBA v0.8.1 – Bookworm pi-gen Baseline

## Ziel

Behebung des GPG-Keyring-Fehlers im ersten vollständigen Image-Build von v0.8.0.

## Ursache

v0.8.0 kombinierte einen für Raspberry Pi OS Trixie vorgesehenen `pi-gen`-Stand mit einem Bookworm-Zielsystem. Der Build scheiterte deshalb bereits in `stage0/00-configure-apt` an fehlenden Debian-Archivschlüsseln.

## Änderung

- Wechsel auf den offiziellen Release-Tag `2026-06-18-raspios-bookworm-arm64`
- Bookworm-Zielsystem und Bookworm-Builder sind wieder aufeinander abgestimmt
- der tatsächlich aufgelöste Git-Commit wird in `image-builder/cache/pi-gen.commit` gesperrt
- Wechsel der `pi-gen`-Basis entfernt automatisch inkompatible `work/`- und `deploy/`-Daten
- ein vorhandenes `pi-gen:latest`-Docker-Image wird beim Basiswechsel entfernt
- Buildplan und Metadaten enthalten den aufgelösten Commit

## Sicherheit

Die APT-Signaturprüfung bleibt vollständig aktiv. Es werden weder `trusted=yes` noch eine deaktivierte GPG-Prüfung verwendet.
