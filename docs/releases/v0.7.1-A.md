# TMBA v0.7.1-A – AudioSource API und Backend CI

## Neu

- abstrakte `AudioSource`-Schnittstelle
- normalisierte Zustände über `SourceLifecycleState`
- `SourceStatus` und `SourceCapabilities`
- thread-sichere `AudioSourceRegistry`
- Unit-Tests für Vertrag, Lebenszyklus und Registry
- GitHub-Actions-Workflow für Backend-Tests
- automatisches Quellpaket nach erfolgreichen Push-Tests

- keine Dummy-PCM-Quelle
- keine direkte Engine-Registry-Integration

Diese Schritte folgen in v0.7.1-B und v0.7.1-C.
