# TMBA-OS v0.6.1-C

## Ziel

Den Status der logischen AudioPipeline über die REST-API verfügbar machen.

## Neu

`GET /audio/pipeline` liefert Pipelinezustand, Stufenanzahl, aktivierte Stufen, OutputDriver-Status, Stufenstatus und Konfiguration. Bei einem Lesefehler antwortet die API mit HTTP 503.

## Architekturänderung

Die Standardquellen werden nicht mehr beim Import von `manager.py`, sondern explizit in `tmba.main` registriert.

## Bewusst nicht enthalten

- keine Schreibzugriffe auf Pipeline-Konfiguration
- kein Frontend
- kein ALSAOutputDriver
- kein CamillaDSP
- keine reale Audioverarbeitung
