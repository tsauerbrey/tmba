# TMBA-OS

> TMBA-OS ist ein speziell entwickeltes Embedded-Betriebssystem für die
> **TMBA – Thoralfs Mobile Beschallungs Anlage**.

## Ziel

Ein schnelles, stabiles und vollständig touchoptimiertes Musiksystem für den Raspberry Pi.

---

## Hardware

- Raspberry Pi 4B (4 GB)
- Original Raspberry Pi 7" DSI Touch Display
- HiFiBerry Amp4 Pro
- HiFiBerry DSP Add-on
- Bourns PEC11R Drehencoder

---

## Audio

- AirPlay
- Bluetooth Audio
- Webradio

---

## Bedienung

- Touch
- Drehencoder
- DSP
- Lautstärke
- Quellenwahl
